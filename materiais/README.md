# Base de dados dos materiais (Fase 1)

Base em formato longo: um registro por propriedade, material e condição de
medição. Cada registro deverá conter, no mínimo:

| Campo | Exemplo |
|---|---|
| material | fita Fe nanocristalina |
| propriedade | permeabilidade relativa inicial |
| valor, unidade | 64000, - |
| frequencia, amplitude, temperatura | 100 Hz; 0,1 A/m; 25 °C |
| forma da amostra, processamento | toroide; recozimento em três etapas |
| incerteza | quando informada pela fonte |
| fonte | referência bibliográfica ou ficha técnica |

O esquema e o validador serão criados no início da Fase 1.
